# minibrain-kit

學員資料包：隊長（焊接廠老闆）**怎麼用開源**。不是主腦、不是 AIWFF、不附 binary。

三條線，不要混：

| 線 | 是什麼 |
|---|---|
| **在用的** | 這台機器上真的有接到、每週還在跑的上游工具 |
| **爬到的** | 看過、留下或丟掉的借鏡。留下的寫為什麼抄、丟掉的寫為什麼不抄 |
| **自己產出的** | 我們寫的小包。不是別人的工具換皮 |

**人：** 把這個 repo 丟給你的 AI，說「讀 `AGENTS.md`，用我聽得懂的方式講隊長怎麼用開源」。  
**AI：** 先讀 [`AGENTS.md`](./AGENTS.md)。

```text
git clone https://github.com/zaxardery8011-design/minibrain-kit.git
```

本期明細：[`weekly/LATEST.md`](./weekly/LATEST.md)

不要為了讀這包去裝任何「小主腦」或 AIWFF。要用六個動詞轉檔／轉錄，另開 [`minibrain-cli`](https://github.com/zaxardery8011-design/minibrain-cli)。
